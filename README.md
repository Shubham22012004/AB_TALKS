# Mini Data Processing System

## Project Overview
This project is a simple Mini Data Processing System built using Python.

The program processes student marks data, stores the information using arrays and hash maps, calculates average scores, and identifies the top-performing student.

---

## Concepts Used

- Arrays (Lists)
- Hashing (Dictionaries)
- Loops
- Conditional Statements
- Data Processing
- Data Analysis

---

## Dataset

The dataset contains marks of students in:
- English
- Maths
- Science

Example:

```python
students = [
    {"name": "KAI", "english": 75, "maths" : 42, "science" : 85},
    {"name": "TYSON", "english": 82, "maths" : 24, "science" : 44},
    {"name": "RAY", "english": 99, "maths" : 88, "science" : 75},
    {"name": "MAX", "english": 90, "maths" : 75, "science" : 74},
    {"name": "DAISI", "english": 92, "maths" : 65, "science" : 93}
]
```

---

## Features

- Processes student records
- Stores marks using dictionaries
- Calculates average marks
- Finds the highest-scoring student
- Displays processed insights

---

## How It Works

1. The dataset is loaded into a list.
2. A dictionary is used as a hash map to store student marks.
3. The program loops through each student record.
4. Average marks are calculated.
5. The student with the highest average is identified.
